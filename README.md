# MOHSIN — Catalogue corrigé

Boutique démo React + Vite : vêtements homme et parfums à Dakhla.

## Lancer le projet

1. Ouvrir ce dossier dans VS Code.
2. Dans le terminal, exécuter `npm install`.
3. Exécuter `npm run dev`.
4. Ouvrir l'adresse locale affichée par Vite.

Le numéro WhatsApp de commande est configuré dans `src/App.jsx` au format international sans `+`.

## Important avant publication

Les photos sont chargées depuis des URL d'images externes. Elles sont utilisées ici comme visuels de démonstration; vérifie les droits d'utilisation et remplace-les par tes propres photos ou des images autorisées avant une mise en ligne commerciale. Confirme aussi les prix et les produits réellement disponibles.
